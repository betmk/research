Each refresh, build the trade book fresh from the most recent Sparta podcast + same-week Deep Dives + HFI / Goh / Crosby / Molinero / Felipe wire and X commentary. Do NOT carry forward stale tier rankings or trade-number labels from prior sessions.

**Why:** User explicit 2026-05-11. The Sparta podcast cadence is ~1/week and trades genuinely change week-to-week. Locking in "Trade #3 = ICE GO/Brent crack" and "Trade #13 = Sing Regrade" across multiple refreshes implies stale priors that may no longer reflect what experts are calling. The trade book is a snapshot of THIS WEEK's expert thinking, not an evolving stable portfolio.

**How to apply:**

- **Pull the most recent Sparta podcast transcript first** (via YouTube auto-captions per `feedback_sparta_podcast_transcript.md`) — that's the authoritative anchor.
- **Build the trade list from the explicit calls in the current episode**, supplemented by same-week Deep Dives and HFI commentary. Each idea is anchored to a specific speaker + episode/piece + timestamp/date.
- **Don't preserve numbered trade slots** (#3, #13, #15 etc.) across refreshes. Re-number from 1 each refresh — or better, drop numbers entirely and label by mechanic (e.g., "Long ICE GO/Brent crack — Crosby Ep 92") so trades can drop in / out without breaking cross-references.
- **Don't carry forward Tier 1 / Tier 2 / Tier 3 rankings** from prior sessions unless the current episode explicitly re-anchors them. Re-rank from scratch using current episode + recency.
- **Trades that were Tier 1 last refresh but get NO mention in the current episode** → drop or move to a "Stale — last anchored N weeks ago" block. They are not active unless the latest expert input re-supports them.
- **Closed/killed/passed trades:** keep these in Appendix for audit trail (the only legitimate use of stable numbered slots, e.g., the historic "#6 HOGO passed" record).
- **The Allocation Summary callout shouldn't lock in either** — refresh fully each time to reflect the new directional landscape.
- **When an explicit Sparta call is for a Singapore product** (per `feedback_no_singapore_trades.md`), note it as directional framework support but do not add as a trade.
